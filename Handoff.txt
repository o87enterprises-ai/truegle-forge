## 🔄 Key Revisions & Decisions

- **Removed ChromaDB / sentence‑transformers** – too heavy for Termux; now use SQLite for history (cloud only) and no vector memory.
- **Local mode** – no conversation history; uses a short, project‑aware prompt (with file tree).
- **Cloud mode** – uses the full Truegle system prompt and logs exchanges in SQLite.
- **Timeout** – set to 180 seconds for local; 60 seconds for summariser (both adjustable).
- **.env secret removed** from Git history (GitHub push protection blocked it).
- **Hugging Face Space** – created via CLI (`huggingface-cli repo create`) to avoid web UI issues on mobile.
